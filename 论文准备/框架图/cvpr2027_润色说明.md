# TaFIR 框架图润色记录

## 配色与版式

- 触觉：青绿色；共同输入、共享主干和正常执行：蓝色。
- 运动历史：淡紫；当前计划：浅金；故障理解：暖橙；恢复执行：绿色。
- 保留原有左侧触觉列、上部模型结构、下部执行—诊断—规划—恢复闭环。
- 统一边框、圆角、字重与间距，避免粗黑边框压过正文。

## 补充的细节

- 标明双指 30 帧输入、Mesh + Flow、左指传感器参考系。
- H100 标明下采样到 11 个机器人状态。
- Need / End 标注 Mean pool → MLP。
- 原 first 改为 Failure tokens，标注自回归解码和 Need → Failure 的 KV cache 复用。
- 动作专家补充 Prefix KV、Flow matching、H = 30。
- 两个阶段均显式标注 Asynchronous monitoring。
- Need = true 对应 Interrupt & hold；End = true 对应 Resume task。
- 脚注明确：共享模型调用串行，状态评估与物理运动重叠。
- 坐标示意保留传感器局部参考与场景参考的区别，局部 Fy 沿传感器长边、Fx 沿短边，Fz 表示法向。

## 生成方式

使用内置 image_gen 工具，以原图为编辑目标，连续进行配色、异步标注和局部坐标细节修订。该文件为栅格设计稿，原始机器人照片宜在最终排版时直接使用原始素材，以保持真实性和清晰度。
