# 近一年触觉具身智能论文梳理：VLA、世界模型与 WAM

检索截止：2026-10-16。主要时间范围为 2025-10-16 至 2026-10-16；表中时间按 arXiv 首版月份或官方技术报告日期标注，不将会议发表年份视为首版公开时间。本表选取代表工作，不作论文数量统计或完整性声明。依据论文页面、方法正文及作者项目页整理；未逐项确认正式录用状态的工作统一作为公开研究论文讨论。

## 一、总体判断

从本次检索的代表工作看，研究已由“增加触觉输入以改善操作”，扩展到以下六类问题：

| 方向 | 核心问题 | 代表工作 |
| --- | --- | --- |
| 动态触觉表征与物理对齐 | 如何表达接触变化、形变、受力和滑移，而不只识别材料或物体？ | AnyTouch 2、TaF-VLA |
| 面向接触的 VLA 融合 | 如何让策略在接触时有效使用触觉，并减少无关触觉干扰？ | TacVLA、DreamTacVLA、HapticVLA |
| 接触预测与世界动作联合建模 | 动作执行后会看到什么、感受到什么，如何据此生成动作？ | VT-WM、ForeTac-VLA、Dream-Tac、Tactile-WAM、VT-WAM |
| 多时间尺度闭环与高效推理 | 如何协调慢速任务理解、动作块生成和快速接触反馈？ | OmniVTA、TouchWorld、Agile-WAM |
| 失败反馈、策略纠正与后训练 | 如何利用失败附近的状态和历史交互改进动作或策略？ | TacCoRL、TACO、ViTaR、PEARS |
| 数据规模、跨传感器与跨本体迁移 | 如何降低机器人触觉数据采集成本并扩大适用范围？ | ToucHD / AnyTouch 2、OmniViTac / OmniVTA、N₀-VTLA、DexTouch-WM |

以上是基于下列论文的归纳，不是互斥分类；同一工作可以涉及多个方向。

## 二、先区分 VLA、世界模型与 WAM

| 类型 | 主要建模对象 | 典型用途 |
| --- | --- | --- |
| 触觉 VLA | 视觉、语言、本体状态、触觉到动作的策略映射 | 直接执行语言指定的接触操作 |
| 视触觉世界模型（WM） | 给定当前状态和候选动作，预测未来视觉与接触状态 | 想象规划、候选动作评价、数据生成、策略评测 |
| 触觉 World Action Model（WAM） | 在同一建模框架中联合预测未来观察与动作 | 用预测的接触演化约束或辅助动作生成 |

这里 WAM 指 **World Action Model**。存在交叉形式：例如 DreamTacVLA 将触觉预测引入 VLA；OmniVTA 将世界模型、动作策略和反射控制器组合。不能因为论文包含未来触觉预测，就直接将其归为统一生成动作与未来状态的 WAM。相关例子见 [DreamTacVLA](https://arxiv.org/abs/2512.23864)、[OmniVTA](https://arxiv.org/abs/2603.19201)、[VT-WAM](https://arxiv.org/abs/2607.02503)。

## 三、触觉 VLA：从融合输入到利用接触演化

| 论文 | 首版月份 | 主要解决的问题 | 方法重点 |
| --- | --- | --- | --- |
| [DreamTacVLA: Learning to Feel the Future](https://arxiv.org/abs/2512.23864) | 2025-12 | 高分辨率触觉与不同尺度视觉难以对齐，策略缺少接触动态理解 | 将触觉作为微观视觉，与腕部及外部视觉作层次空间对齐，并用未来触觉预测增强策略 |
| [TaF-VLA](https://arxiv.org/abs/2601.20321) | 2026-01 | 将触觉仅当成视觉纹理，难以理解真实作用力 | 将高维触觉表征显式对齐到交互力，再接入 VLA |
| [TacVLA](https://arxiv.org/abs/2603.12665) | 2026-03 | 无接触阶段的触觉可能干扰融合，接触时又需要有效利用触觉 | 接触感知门控，在检测到接触时激活触觉 token；评测包括遮挡与人为扰动 |
| [HapticVLA](https://arxiv.org/abs/2603.15257) | 2026-03 | 触觉硬件增加部署成本，能否只在训练时使用触觉？ | 安全触觉奖励加权训练，再将触觉能力蒸馏到仅使用视觉和状态的学生策略 |
| [N₀-VTLA](https://arxiv.org/abs/2607.23782) | 2026-07 | 缺少规模化接触先验，部署数据难以用于持续改善 | 大规模视触觉预训练、分阶段引入预测触觉通路，以及基于部署数据的离线策略改进 |
| [ForeTac-VLA](https://arxiv.org/abs/2609.20980) | 2026-09 | 仅根据已观察接触作反应，无法预先考虑接触变化 | 时序触觉编码、多步触觉预测、双向跨模态注意力，用预测接触条件化动作 |

这条研究线的共同问题是：**如何让触觉真正影响策略，而不只是给模型多输入一段数据。** 关注点包括物理含义、接触门控、时序预测和部署成本；不能用“拼接触觉 token”概括这些方法。

## 四、触觉世界模型与 WAM：让未来接触成为预测对象

| 论文 | 首版月份 | 类型与主要重点 |
| --- | --- | --- |
| [Visuo-Tactile World Models（VT-WM）](https://arxiv.org/abs/2602.06001) | 2026-02 | 多任务视触觉世界模型；借助接触信息减少遮挡和接触歧义导致的物理不一致，支持想象与规划 |
| [OmniVTA](https://arxiv.org/abs/2603.19201) | 2026-03 | 两路视触觉世界模型预测短时接触演化，配合接触融合策略与 60 Hz 反射控制器 |
| [VTAM](https://arxiv.org/abs/2603.23481) | 2026-03 | 向预训练视频动作模型加入触觉，以轻量模态迁移和注意力正则学习接触交互 |
| [Dream-Tac](https://arxiv.org/abs/2606.08737) | 2026-06 | 联合建模动作、未来视觉和触觉；使用接触门控、接触注意力及缓存加速 |
| [Tactile-WAM](https://arxiv.org/abs/2606.26663) | 2026-06 | 研究触觉注入对视觉动态的干扰，通过非对称注意力保护视觉路径，同时让动作利用触觉 |
| [VT-WAM](https://arxiv.org/abs/2607.02503) | 2026-07 | 在 flow matching 中联合预测视觉、触觉形变与动作；通过非对称专家交互和接触期注意力引导减少视觉主导 |
| [FeelWorld](https://arxiv.org/abs/2607.24267) | 2026-07 | 将接触状态、力相关三维触觉潜变量和滑移状态分层预测，用于接触感知 CEM 规划 |
| [N₀-TWAM（官方技术报告）](https://research.neoteai.com/n0-twam/) | 2026-07 | 区分预测触觉与当前观测触觉两条通路，分别服务预判和反馈，并用触觉事件辅助长任务阶段切换 |
| [Agile-WAM](https://arxiv.org/abs/2609.20761) | 2026-09 | 在潜空间联合生成动作与未来视触觉；使用不同预测时间尺度，减少对昂贵视频生成推理的依赖 |
| [DexTacWAM](https://arxiv.org/abs/2609.24976) | 2026-09 | 将多指触觉动态接入预训练视频世界模型，经触觉压缩和预测特征接口服务灵巧手动作生成 |

这里最值得关注的是三个问题：

1. **物理一致性：**视觉上合理的未来，不一定对应夹稳、插入或未滑移的真实接触。VT-WM、FeelWorld 直接将接触信息纳入预测。
2. **模态交互：**触觉具有局部、稀疏、事件驱动的特点；简单全连接注意力可能让视觉压过触觉，或让触觉干扰原有视觉模型。Tactile-WAM 与 VT-WAM 分别设计信息流约束。
3. **推理效率：**完整生成未来视频代价较高，但控制需要及时动作。Dream-Tac、Agile-WAM、DexTacWAM 分别从缓存、潜空间和预测特征读取等角度处理。

上述三点是对表中方法的综合归纳，不表示所有工作都具备完整长时规划或通用物理模拟能力。

## 五、多时间尺度与闭环控制

| 论文 | 闭环方式 | 与显式故障恢复的关系 |
| --- | --- | --- |
| [OmniVTA](https://arxiv.org/abs/2603.19201) | 预测短期接触，低层依据预测与实测触觉偏差作 60 Hz 纠正 | 重点是局部接触跟踪与反射纠正 |
| [TouchWorld](https://arxiv.org/abs/2607.07287) | 视觉语言子任务规划、触觉子目标预测、名义动作块、快速触觉残差纠正分层 | 已评测人为扰动下的恢复，不能归为只考虑理想执行的工作 |
| [ViTaR](https://arxiv.org/abs/2608.15816) | 冻结 VLA，用结果偏好证据选择并缩放有界残差 | 重点是保持基础策略能力的同时调制当前执行 |
| [Agile-WAM](https://arxiv.org/abs/2609.20761) | 轻量潜空间建模，分别监督较远视觉和近时触觉 | 重点是预测与控制效率，不等于具备独立的语义故障诊断流程 |

应区分“低层接触纠正”“阶段级故障恢复”“跨回合策略适应”。它们都可能提高扰动鲁棒性，但解决的问题和实验协议不同。

## 六、失败反馈、后训练与历史适应

| 论文 | 首版月份 | 如何使用失败或反馈 | 主要作用层级 |
| --- | --- | --- | --- |
| [TacCoRL](https://arxiv.org/abs/2606.11743) | 2026-06 | 仿真与真实数据联合训练，再通过仿真 RL 学习示教中稀少的近失败接触响应 | 策略训练与 sim-to-real 迁移 |
| [TACO](https://arxiv.org/abs/2607.02840) | 2026-07 | 识别失败附近状态，联合想象视觉与触觉纠正片段，再标注动作并筛选，用于迭代后训练 | 从 rollout 失败构造纠正训练数据 |
| [ViTaR](https://arxiv.org/abs/2608.15816) | 2026-08 | 以结果相关的偏好证据判断局部纠正，再选择有界动作残差及其强度 | 冻结基础策略的执行调制 |
| [PEARS](https://arxiv.org/abs/2610.08784) | 2026-10 | 每个 episode 后，结合视觉结果、触觉力历史和已有接触力范围推理失败原因并更新力范围；同时用 RL 调整冻结策略的噪声 | 跨 episode 的历史适应与接触控制 |

尤其需要避免两种混淆：TACO 的主要流程是**利用失败构造数据并更新策略**，不能直接等同于本项目“运行中生成恢复计划”；PEARS 确实具有**故障推理和累积历史**，但其主要历史更新位于 episode 之间，更新对象是接触力范围等适应变量。相关判断依据 [TACO 方法](https://arxiv.org/html/2607.02840v2) 与 [PEARS 方法](https://arxiv.org/html/2610.08784v1)。

## 七、基础表征与数据扩展

- [AnyTouch 2 / ToucHD（2026-02）](https://arxiv.org/abs/2602.09617)：明确研究动态触觉感知，覆盖原子交互、真实操作及触觉—力配对，兼顾跨传感器与细粒度动态表征。因此不能再将“由静态属性转向动态接触”单独视为足够的创新。
- [OmniViTac / OmniVTA（2026-03）](https://arxiv.org/abs/2603.19201)：以多任务、多物体及物理交互模式组织视触觉动作数据，服务预测、策略与反馈控制的联合研究。
- [N₀-VTLA（2026-07）](https://arxiv.org/abs/2607.23782)：研究大规模触觉预训练、分阶段适配和部署数据驱动的离线改进。
- [DexTouch-WM（2026-09）](https://arxiv.org/abs/2609.20649)：利用人手与机器人兼容的触觉布局及动作重定向，从人类触觉交互扩展机器人世界模型训练数据；关注预测、策略评估及合成数据学习。

这些工作将数据问题从“能否采到触觉”推进到“如何采到有接触动态、可迁移、可用于控制的数据”。该表述是对上述研究目标的综合归纳。

## 八、对本项目定位的影响

### 1. 背景叙事需要收窄

不宜将近年的研究整体概括为“只对原定动作进行精修，没有故障理解或恢复”。TacVLA 已报告扰动恢复，TouchWorld 专门组合预测与反应，TACO 和 PEARS 则分别涉及失败纠正后训练和故障历史推理。

较稳妥的研究问题表述是：

> 触觉增强策略与预测接触模型已改善接触操作的精度和鲁棒性。本文进一步关注执行中已发生的接触故障：如何将局部动态触觉证据解释为可用于恢复的故障语义，并结合已执行恢复操作及其后续反馈，在执行与恢复之间自主切换。

这是一种研究定位，不是已完成的“现有工作均未做到”证明。最终新颖性判断仍需对最接近方法作任务与模块层面的对照。

### 2. 三个贡献分别需要证明什么

| 本项目贡献 | 最近工作的相关性 | 更应强调与验证的内容 |
| --- | --- | --- |
| 离散触觉元描述 | AnyTouch 2 已研究时序动态；TaF-VLA 已研究物理对齐；更早 CLTP 已研究触觉语言 | 少量有明确物理含义的接触状态字段，是否以低成本保留诊断和恢复所需信息；不能只强调离散或文本格式 |
| 故障诊断与历史恢复推理 | PEARS 已用历史诊断失败；TACO 已处理失败附近纠正 | 同一任务运行中，依据已执行恢复操作及其后续 failure 改变新 plan；用同故障不同历史的对照证明方向和程度的变化 |
| 执行与恢复触觉闭环 | OmniVTA、TouchWorld 已有预测与快速反馈；N₀-TWAM 已用触觉辅助阶段切换 | 异常发现后的及时中断、独立恢复启动/终止与任务续执行，及它们对多轮恢复的作用；异步和闭环本身不宜作孤立首创宣称 |

表中“更应强调”是结合本项目设计提出的写作与实验建议，不等于这些优势已通过现有实验建立。当前 Bottle 训练中的固定故障—计划对应和合成 L1–4 文本历史，不能单独支撑一般化的历史策略更新结论。

### 3. 精读顺序

最接近本项目的问题线：**VLA-Touch → Tactile-VLA → TouchWorld → TACO → PEARS**。表征线补充 **CLTP、AnyTouch 2、TaF-VLA**。WAM 线先读 **VT-WM、VT-WAM、Tactile-WAM**，再读 **Agile-WAM** 对比预测对象、信息流和控制代价。

## 九、时间范围之外但必须对照的前序工作

以下首版早于本次一年窗口，作为研究脉络与近邻工作，不计入窗口内论文：

| 工作 | 首版月份 | 与本项目的关系 |
| --- | --- | --- |
| [CLTP](https://arxiv.org/abs/2505.08194) | 2025-05 | 触觉与语言对齐、接触几何理解；描述范围不能概括为只有静态粗糙度或形状 |
| [Tactile-VLA](https://arxiv.org/abs/2507.09160) | 2025-07 | 多模态触觉融合、位置—力控制及触觉相关自适应推理 |
| [VLA-Touch](https://arxiv.org/abs/2507.17294) | 2025-07 | 语义触觉支持高层规划、触觉控制器精修动作的双层集成 |
| [OmniVTLA](https://arxiv.org/abs/2508.08706) | 2025-08 | 跨不同类型传感器的触觉编码和语义对齐，服务 VLA 操作 |

后续正式相关工作应按问题与方法分组，不以名称中是否含 VLA 或 WAM 作为唯一标准。
