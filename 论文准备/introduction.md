# Introduction

视觉–语言–动作（Vision–Language–Action, VLA）模型将视觉语言知识与机器人控制相结合，推动了面向开放环境的通用操作能力发展。[π0.5](https://arxiv.org/abs/2504.16054) 等模型已展示跨场景的长时任务执行能力，但物理交互的可靠性仍取决于视觉难以直接观测的接触状态：夹爪闭合并不意味着物体已被稳定夹持，末端到达目标位置也不意味着接触或装配已经完成。触觉提供的受力、形变与接触变化信息，为弥补这一感知缺口提供了直接依据。近年来，[Tactile-VLA](https://arxiv.org/abs/2507.09160) 和 [TaF-VLA](https://arxiv.org/abs/2601.20321) 等工作将触觉与策略学习、物理力信息相结合，使机器人能够更准确地执行接触密集操作。

现有研究从多个层面利用触觉提高操作鲁棒性。[VLA-Touch](https://arxiv.org/abs/2507.17294) 将语义触觉反馈用于高层规划，并通过触觉控制器精修动作；[VT-WAM](https://arxiv.org/abs/2607.02503) 将未来视觉、触觉形变与动作联合建模，使接触演化参与动作生成；[TouchWorld](https://arxiv.org/abs/2607.07287) 进一步结合接触预测与快速残差纠正，以应对执行中的局部扰动。这些进展改善了接触感知与控制，但在真实环境中，物体偏移、夹取失衡或异常接触仍可能使既定动作失效。例如，夹爪与物体之间已经发生相对偏转时，继续执行原来的旋转动作可能无法完成任务。此时，机器人需要判断接触故障是什么、应采取何种恢复操作，以及何时能够继续原任务。因此，理解已经发生的接触故障，并据此作出恢复决策，是实现可靠自主操作的重要问题。

针对已经发生的操作失败，[TACO](https://arxiv.org/abs/2607.02840) 能够从失败附近的状态自主生成视触觉恢复轨迹，用于策略后训练，但生成过程尚缺少由失败原因显式确定的恢复目标，主要通过预测任务进度评价和筛选候选轨迹。[PEARS](https://arxiv.org/abs/2610.08784) 在这一点上进一步引入视觉语言模型的推理能力，将失败分析转化为针对性的接触力调整方案，使恢复具有明确的物理目标。然而，其推理得到的方案主要限于预定控制轴上的力或力矩幅值调整，尚未扩展为针对位置偏移、姿态偏差等多类接触故障的恢复计划；而且，上述方案在一轮任务结束后更新，并用于下一轮执行。对于状态演化不可逆或难以重置的任务，这种依赖再次执行的适应方式难以满足当前任务中及时恢复的需求。因此，本文进一步关注**同一次任务执行中面向多类接触故障的在线恢复**：结合视觉与动态触觉理解具体故障，推理具有明确方向与程度的恢复计划，并依据历史恢复反馈持续更新策略，使机器人能够在当前任务中完成多轮恢复并继续执行。

实现这一目标需要贯通三个环节。首先，连续时序触觉中包含丰富的局部接触变化，需要将其提炼为简洁且具有物理含义的状态表达。[CLTP](https://arxiv.org/abs/2505.08194) 已探索接触状态的触觉语言对齐，[AnyTouch 2](https://arxiv.org/abs/2602.09617) 则研究细粒度动态触觉表征；面向故障恢复，还需要使这些接触信息能够直接支持故障解释与策略选择。其次，传感器局部坐标系中的受力与旋转现象并不直接对应全局空间中的故障方向，需要结合视觉中的夹爪和物体姿态加以解释，并利用历史操作及其后续故障反馈确定恢复方向与程度。最后，恢复决策必须与动作执行协调：系统既要在动作执行期间发现异常并及时中断，也要判断当前恢复何时结束，避免持续执行已失效的动作或不必要的恢复操作。

为此，本文提出一种动态触觉驱动的故障诊断与闭环恢复框架。我们首先设计轻量化触觉描述器，通过空间编码与时序卷积，将连续双指触觉信号离散为触觉元描述文本。描述器以接触面积、三轴受力和旋转五类元字段，表征常见动态接触状态，其中受力组合同时表达双指同向、异向及法向强弱差异。在此基础上，模型结合视觉，将左指传感器局部坐标系下的接触证据解释为全局空间中的故障状态，并将已执行的恢复计划与其后续故障反馈配对记录。恢复推理依据这些历史结果选择下一步操作，使恢复方向与程度随实际反馈更新。该设计将动态触觉感知、故障解释和恢复决策连接起来，为任务中的连续恢复提供语义依据。

框架基于共享的 π0.5 主干实现状态判断、故障诊断、恢复规划与动作生成。恢复计划作为动作生成的条件，将推理结果落实为机器人运动。为协调模型推理与物理执行，我们将状态评估与动作执行异步解耦：机器人执行动作块时，后台持续评估是否需要启动恢复；触发异常后，系统及时中断动作，完成诊断与恢复规划。恢复执行期间，系统评估恢复进度，自主结束当前恢复并返回原任务；若后续仍检测到故障，则结合更新后的历史开展下一轮恢复。由此，触觉反馈既用于理解异常，也用于控制执行与恢复阶段的切换，形成从故障发现、恢复决策到任务续执行的闭环。

本文的主要贡献如下：

- **离散化的触觉元描述。** 提出轻量化时序触觉描述器，将连续双指触觉编码为具有物理含义的离散元描述文本，以少量字段表征接触面积、受力组合与旋转等动态接触状态，为故障诊断和恢复推理提供简洁的语义输入。

- **基于触觉的故障诊断和恢复推理方法。** 结合视觉与局部触觉元描述推理全局空间中的接触故障，并依据已执行恢复计划及其后续故障反馈，确定下一步恢复方向与程度，支持任务执行中的多轮恢复决策。

- **执行与恢复的触觉闭环框架。** 在动作执行期间异步评估执行状态与恢复进度，自主判断恢复的启动与结束，支持动作块内中断、执行与恢复阶段切换，以及恢复后的任务续执行。
